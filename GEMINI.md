# Panduan Proyek Qurbi

## Stack & Tools Utama
- Runtime & Package Manager: Node.js / npm
- Bahasa: TypeScript
- ORM & Database: Prisma (`prisma.ts`)
- Testing Framework: Vitest (`npx vitest run`)

## Aturan Kerja Agen
- Gunakan Bahasa Indonesia untuk semua penjelasan dan ringkasan.
- Sebelum menyelesaikan tugas, pastikan tidak ada error TypeScript (`npx tsc --noEmit`) dan unit test terkait berjalan sukses (`npx vitest run`).
- Jangan melakukan `git commit` atau `git merge` kecuali diminta secara eksplisit.
- Buat ringkasan padat (maksimal 20 baris) beserta daftar file yang diperbarui setelah selesai mengedit kode.
